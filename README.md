# Справочник децимальных кодов ЕСКД

Автономный HTML-инструмент (один файл, без сборки) для работы с обезличенными обозначениями изделий и конструкторских документов вида `АБВГ.426444.001 Э3`.

**Открыть онлайн:** https://wadi-li.github.io/eskd-decimal-code/ (после включения GitHub Pages) или скачать `eskd_decimal_code.html` и открыть в браузере (работает без интернета).

## Возможности

- **Расшифровка** обозначения: код организации (буквенный / цифровой), иерархия по классификатору ЕСКД (ОК 012-93), регистрационный номер, исполнение, код документа.
- **Кодирование** нового изделия, шаблоны комплектов КД, экспорт CSV, локальный реестр.
- **Коды РЭА**: печатные платы (7587хх, 7588хх, 68725х, 68726х), платы в сборе (469135, 469635), функциональные модули (468х, 467), телемеханика (4264х); мастер подбора кода.
- **Коды документов**: ГОСТ Р 2.102-2023, ГОСТ Р 2.601-2019, ГОСТ 2.602-2013, ГОСТ 2.701-2008.
- **Встроенный полный классификатор ОК 012-93** (v4): 79 910 кодов всех 44 классов до уровня вида, включая классы 36 и 46; источники — classinform.ru и prilan.ru с перекрёстной сверкой.
- **Онлайн-подгрузка** классификатора (для сверки) и кеш в IndexedDB, нормализация кодировок (UTF-8 / windows-1251 / KOI8-R).
- Светлая тема по умолчанию, переключение на тёмную.

## Ограничения

- База собрана из открытых справочных сайтов, а не из официального издания: 169 наименований обрезаны в источнике (помечены «…»), 73 кода опубликованы без наименования — сверяйте по ОК 012-93.
- Требуется браузер с поддержкой DecompressionStream (Chrome/Edge 80+, Firefox 113+, Safari 16.4+).
- Реестр обозначений хранится в браузере — делайте экспорт в JSON.
